# Караоке-баттл

Браузерная игра: выбираешь фрагмент песни, поёшь в микрофон и получаешь оценку за попадание в мелодию и ритм. Проект сделан на хакатоне «Время IT» 2026, тема «Караоке-баттл».

## Что умеет

- **Шесть фрагментов** трёх уровней сложности. Мелодии и тексты наши, звук синтезируется в браузере через Web Audio API, поэтому никаких аудиофайлов и проблем с правами.
- **Пение в реальном времени.** Ноты эталона едут по экрану, голос рисуется поверх них линией: зелёной, когда попадаешь, розовой, когда мимо. Подсказка показывает, брать выше или ниже.
- **Караоке-текст** с заливкой слогов в такт.
- **Разбор результата:** баллы из 1000, отдельно мелодия и ритм, график «ты и эталон», советы, какую строчку подтянуть, и запись своего исполнения.
- **Повторные попытки** и личный рекорд по каждому треку.
- **Дуэль:** двое поют один фрагмент по очереди, побеждает тот, кто точнее.
- **Таблица лидеров** с фильтром по трекам.

## Как запустить

Нужен только браузер (лучше Chrome или Edge) и микрофон.

1. Скачайте проект.
2. Откройте `index.html` в браузере. Если микрофон не включается, запустите локальный сервер: в VS Code расширение **Live Server**, правый клик по `index.html`, «Open with Live Server».
3. Разрешите доступ к микрофону и нажмите на розовую кнопку.

Онлайн-версия работает через GitHub Pages.

## Как считается оценка

1. Звук с микрофона 60 раз в секунду проходит через алгоритм YIN, который находит основную частоту голоса и переводит её в ноту.
2. Каждая нота эталона сравнивается с тем, что спел игрок в это время. Октава не важна: низкий и высокий голос оцениваются одинаково.
3. **Мелодия** (60% оценки): насколько близко к нужной ноте. В пределах полутона засчитывается полностью, дальше баллы снижаются.
4. **Ритм** (40% оценки): вовремя ли начата нота и держится ли она всю длительность.
5. Итог переводится в баллы от 0 до 1000 и ранг от D до S.

## Структура

```
index.html      разметка страницы
css/style.css   стили и анимации
js/tracks.js    треки: ноты, тексты, аккорды
js/sound.js     звук: синтезатор, микрофон, определение высоты голоса
js/score.js     подсчёт оценки и советы
js/app.js       экраны, навигация, дуэль, таблица лидеров
```

## Технологии

HTML, CSS, JavaScript без фреймворков. Web Audio API, MediaRecorder, Canvas, localStorage.
